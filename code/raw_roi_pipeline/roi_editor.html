PhenoSight ROI Editor

Draw one region per pot on the RGB previews written by phenosight_raw.py. Only chlorophyll-fluorescence (Fm) mask pixels inside each region are scored, so a loose box around a pot is fine.

x — · y — px
Example tray with five example regions (squares and circles). Load your own previews to start.
Square / rectangle: drag across a pot. Circle: drag from the pot centre outwards. Polygon: click vertices, then Enter or click the first point. Edit: drag a corner or the whole region; Delete removes the selected region.
